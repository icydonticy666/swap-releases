# swap

**swap** arregla dos problemas de proyectos de **FL Studio** y **Ableton Live**:

- **Cambiar versión**: abre en tu versión un proyecto hecho en una más nueva. swap detecta solo qué versión tienes.
- **Arreglar plugins**: cambia los VST2 que ya no cargan por su VST3 instalado, con los mismos ajustes.

El archivo original no se toca nunca: swap deja una copia en la misma carpeta.

## Descargar

Ve a [**Releases**](../../releases/latest) y baja el archivo de tu sistema:

| Sistema | Archivo |
|---|---|
| Windows | `swap-…-windows-instalador.exe` (o el `.zip` portable) |
| Mac con Apple Silicon (M1, M2, M3, M4) | `swap-…-mac-apple-silicon.dmg` |
| Mac con Intel | `swap-…-mac-intel.dmg` |

Una vez instalado, swap avisa solo cuando hay una versión nueva y se actualiza con un clic.

## Primera vez

- **Windows**: si aparece «Windows protegió su PC», pulsa *Más información* → *Ejecutar de todas formas*.
- **Mac**: si macOS no deja abrirlo, ve a *Ajustes del Sistema → Privacidad y seguridad* y pulsa *Abrir igualmente*.

Versión de prueba (beta) de IceRoom.
